# 짐메이트 (GymMate) — UI 디자인 브리프

> 회원님 → AI 디자인 툴(v0, Figma AI, ChatGPT 등) 또는 디자이너에게 그대로 전달 가능한 문서.

---

## 1. 프로젝트 개요

- **이름**: 짐메이트 (GymMate)
- **URL**: https://gymmate-eight.vercel.app
- **타입**: PWA — 모바일 웹앱, iPhone 홈화면 추가 시 앱처럼 실행
- **한 줄 소개**: 친한 친구 5~20명이 헬스장 출석을 서로 공유하고 주간 목표 달성률을 겨루는 앱
- **현재 상태**: 기능 완성, UI는 아직 프로토타입 수준 (검정 선 + 여백 위주)

## 2. 타깃 사용자

- 20~30대, 헬스장 다니는 친구/운동 메이트 그룹
- 서로 은근한 압박 주면서 재밌게 동기 부여받고 싶은 사람들
- 주 사용 환경: **iPhone Safari** (모바일 세로 방향)

## 3. 톤 & 무드

- **친근하고 명랑** (기업 앱 느낌 X, 인스타/토스처럼 부드러운 개인성)
- **소셜 게임처럼 가벼운 재미** (Duolingo 같은 게이미피케이션 요소)
- **심플, 정보 밀도 낮게** — 각 화면 한눈에 파악
- 프리티한 그라디언트/일러스트는 최소, 스마트한 여백
- 라이트 모드만 (다크는 추후)
- 폰트: 한글 시스템 폰트 or **Pretendard** 계열

## 4. 색상 방향 (제안 — 자유롭게 변경 가능)

현재 코드는 순수 검정/흰색만 사용. 아이덴티티 색이 필요:

- **Primary** (버튼, 강조): 활력 있는 색. 예: 오렌지(#FF6B35), 라임그린(#3DDC97), 코발트블루(#0052FF) 중 하나
- **Success** (체크인 완료): 초록 #22C55E
- **Danger** (오류/로그아웃): 빨강 #EF4444
- **Text**: #0F172A (거의 검정), 서브텍스트 #64748B
- **Background**: #FFFFFF, 카드 배경 #F8FAFC
- **Border**: #E2E8F0

## 5. 화면 인벤토리 (9개)

### 5-1. 로그인 (`/login`)
- 앱 로고/이름 상단
- 이메일 입력 필드
- "로그인 링크 받기" 버튼
- 이메일 발송 후 확인 메시지 표시

### 5-2. 온보딩 (`/onboarding`) — 3단계 위저드
- Step 1: 닉네임 입력
- Step 2: 헬스장 등록 — 이름 자유 입력 + "📍 여기가 내 헬스장" GPS 버튼 (누르면 현재 좌표 저장, 시각적 피드백 필요)
- Step 3: 주간 목표 선택 — 2/3/4/5/6/7회 그리드 (선택 시 강조)

### 5-3. 오늘 탭 (`/today`)

앱의 홈 화면. 3 영역 구조로 **성취감 자극 + 명확한 primary action + 기록 접근**을 동시에 커버.

**상단: 통계 카드 (성취감 영역)**
- 누적 방문: "총 12일째 다니는 중" (온보딩 이후 distinct days 카운트)
- 이번주 진행률: 프로그레스 바 + "3 / 5일" (기존 유지, 좀 더 크게)
- 트렌드: "이번달 12회 · 지난달 8회" (증감 화살표 ↑↓ 색상 표시)

**중앙: Hero CTA**
- 큰 "오늘 헬스 감" 버튼 (탭 → GPS/사진 인증 흐름 시작)
- 시각적으로 화면의 무게중심. 넉넉한 세로 폭.
- 선택 메모 입력 필드는 버튼 아래

**하단: 이번주 미니 캘린더 + 오늘 기록**
- 이번주 요일 7칸 뱃지 (월화수목금토일) — 다녀온 요일에 색상 채움, 오늘은 테두리 강조
- **이 미니 캘린더 탭 시 → 캘린더 탭으로 이동** (자연스러운 딥링크)
- 그 아래: 오늘 기록 리스트 (시간, 📍 or 📷 아이콘, 메모, 사진 썸네일)
- 오늘 기록 없으면 "아직 오늘 기록이 없어요" 짧은 안내

**설계 원칙:**
- Primary action(체크인)이 시각적으로 가장 강력해야 함 — hero CTA 위치/크기 확실히
- 상단 통계는 "지금까지 잘 해왔네" 느낌으로 진입 순간 성취감 자극
- 하단 미니 캘린더는 캘린더 탭 진입의 자연스러운 실마리 (탭 바 사용을 대체하는 게 아니라 보조)

### 5-4. 캘린더 탭 (`/calendar`)
- 월별 캘린더 그리드 (월요일 시작, 한국 관습)
- 체크인한 날짜에 도트/색 표시
- 이전/다음 월 화살표
- 날짜 탭 시 하단에 그날 상세 리스트

### 5-5. 그룹 탭 (`/groups`)
- 상단: 그룹 스위처 드롭다운 + "새 그룹" 링크
- **초대 링크 복사 카드**: URL 표시 + 탭하면 클립보드 복사 (피드백 필요)
- **이번주 달성률**: 각 멤버별 프로그레스 바 + %
- **최근 활동 피드**: 누가/언제/방식(📍 or 📷)/메모/사진 (최근 20개)
- 방장이면 추가: 멤버별 "추방" 버튼 + "새 초대 링크 발급" 버튼

### 5-6. 그룹 없음 상태 (empty state)
- 안내 메시지 + "새 그룹 만들기" 큰 버튼 (친절하고 유도력 있게)

### 5-7. 새 그룹 만들기 (`/groups/new`)
- 그룹 이름 입력 + "만들기" 버튼

### 5-8. 초대 링크 진입 (`/join/[code]`)
- 그룹 이름 표시
- 로그인 필요 시 로그인 유도 카드
- 로그인 상태면 자동 참여 후 그룹 탭으로 리다이렉트

### 5-9. 설정 탭 (`/settings`)
- 닉네임 편집 필드
- 주간 목표 편집 (2~7회 그리드, 온보딩과 동일 스타일)
- 헬스장 카드 (이름/좌표 표시) + "변경" 버튼 → GPS 재등록
- 로그아웃 버튼 (빨간색)

## 6. 공통 요소

### 하단 탭 바 (모든 (app) 라우트에 노출)
- 4개 탭: **오늘 | 캘린더 | 그룹 | 설정**
- 활성 탭: 색상 or 굵기로 강조 + 아이콘 채움 스타일
- iOS safe area 하단 여백 고려
- 아이콘 추가 필요 (현재는 텍스트만)

### 체크인 흐름 (오늘 탭 내부, 상태별 UI)
- **idle**: 큰 "오늘 헬스 감" 버튼 + 선택 메모 입력창
- **gps**: "위치 확인 중..." 로딩
- **photo-required**: 안내 문구 + "📷 카메라로 인증" 버튼 (카메라만 열림, 갤러리 X)
- **saving**: "저장중..."
- **done**: 초록 체크 + "체크인 완료!" (1.5초 후 페이드아웃)
- **error**: 빨간 메시지 + "다시 시도" 링크

## 7. 컴포넌트 인벤토리

디자인이 필요한 컴포넌트 리스트:

- 버튼: **Primary** (검정→새 컬러) / **Secondary** (테두리만) / **Danger** (빨강)
- 큰 액션 버튼 (오늘 헬스 감 — 세로로 넉넉)
- 인풋 필드 (이메일, 닉네임, 그룹명, 메모)
- 카드 (기록, 초대 링크, 헬스장 정보 등)
- 프로그레스 바 (진행률, 달성률)
- 캘린더 그리드 셀 (일반/오늘/체크인/이번 월 밖)
- 통계 카드 (누적 방문 / 이번주 진행률 / 월별 트렌드 등 홈 상단용)
- 이번주 요일 미니 뱃지 (7칸, 다녀온 요일 채움, 오늘 강조)
- 드롭다운 (그룹 스위처)
- 리스트 아이템 (활동 피드 카드)
- 이미지 썸네일 (체크인 사진, 클릭 시 확대)
- 로딩 스피너
- 완료 체크 애니메이션 (선택)
- 하단 탭 바 아이콘 4개 (오늘/캘린더/그룹/설정)
- PWA 앱 아이콘 (홈화면용 512x512)

## 8. 기술 제약 (디자이너가 알아야 할 것)

- **Tailwind CSS v4** — 커스텀 색상은 CSS 변수로 정의
- **Next.js 16 App Router** + React 19
- 이미지: SVG 아이콘 선호 (react-icons, heroicons 등), 로컬 PNG도 가능
- **모바일 세로 우선** (min-width 320px, max-width 428px 커버)
- iPhone Safari safe area (홈 인디케이터 공간) 고려
- 애니메이션은 Tailwind 기본 (transition, animate-pulse 등) 위주, 무거운 라이브러리 지양
