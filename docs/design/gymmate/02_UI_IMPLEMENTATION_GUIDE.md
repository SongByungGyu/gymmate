# GymMate 코발트 블루 UI 구현 지시서 — 이미지 허용 정정본

## 목적

현재 구현된 GymMate의 기능과 데이터 흐름을 유지하면서 `03_gymmate-cobalt-ui-reference.png`의 코발트 블루 색감, 여백, 정보 위계, 컴포넌트 분위기를 실제 코드에 반영한다.

Figma로 옮기지 않고 현재 Next.js 코드에 직접 적용한다.

---

## 참조 자료 우선순위

충돌 시 아래 우선순위를 따른다.

1. 현재 서비스의 실제 기능, 데이터, 인증, 권한, API 계약
2. `01_IMAGE_POLICY_CORRECTION.md`
3. 이 구현 지시서
4. 원본 디자인 브리프
5. 참조 이미지의 색감과 레이아웃 분위기
6. 참조 이미지 안의 임의 문구, 샘플 데이터, 얼굴 사진

참조 이미지 안의 사람 얼굴 및 프로필 아바타는 복제하지 않는다. 다만 체크인 사진 썸네일, 로고, 아이콘, 비인물 이미지 사용은 허용한다.

## 앱 성격

- 앱명: GymMate / 짐메이트
- 형태: 모바일 우선 PWA
- 주요 환경: iPhone Safari 세로 화면
- 핵심: 친구 5~20명이 헬스장 출석을 공유하고 주간 목표 달성률을 확인
- 제품 성격: 전문 운동 분석 앱보다 친구끼리 쓰는 가벼운 운동 출석부

## 이미지 정책 요약

### 사용

- 실제 사진 인증으로 등록된 체크인 사진
- 오늘 기록, 캘린더 상세, 그룹 피드의 체크인 사진 썸네일
- 사진 확대 보기
- 앱 로고, 앱 아이콘, SVG 기능 아이콘
- 비인물 일러스트 또는 장식 이미지

### 미사용

- 사용자 프로필 사진
- 그룹 멤버 얼굴 사진
- 랜덤/AI 프로필 이미지
- 이니셜 아바타나 원형 이름 배지

### 사람 표시 방식

- 닉네임 텍스트만 사용
- 필요 시 `나`, `방장`, `목표 완료` 같은 작은 상태 텍스트만 추가
- 이름 앞에 빈 아바타 공간을 확보하지 않음

## 공통 비주얼 원칙

1. 흰색과 따뜻한 회백색을 기반으로 한다.
2. 정보 위계는 타이포와 여백을 우선한다.
3. 한 화면의 강한 Primary CTA는 최대 하나다.
4. 카드 남발과 카드 안의 카드를 피한다.
5. 그림자는 기본적으로 사용하지 않는다.
6. 원형 프로그레스 링은 사용하지 않는다.
7. 아이콘은 Lucide 또는 Heroicons 한 세트로 통일한다.
8. 사용자 표시에는 아바타 없이 닉네임만 쓴다.
9. 체크인 사진은 실제 데이터가 있을 때 분명하게 보여준다.
10. 사진이 없는 기록에는 빈 썸네일 칸을 만들지 않는다.
11. 기존 카메라, GPS, 업로드, 저장, 권한 로직은 보존한다.
12. iPhone Safari safe area와 터치 영역을 고려한다.

## 공통 컴포넌트

### 버튼

- Primary: `#2563EB`, 흰색 텍스트, 56px, radius 14px
- Secondary: 흰 배경 + border
- Danger: danger-soft 또는 흰 배경 + 빨간 텍스트
- 아이콘과 텍스트 간격 8px

### 입력

- 높이 52~56px
- 흰 배경, 1px border
- focus 시 cobalt ring
- label/helper/error 위계 일관성 유지

### 사용자 이름 행

- 프로필 이미지와 아바타 없음
- 왼쪽 정렬된 닉네임이 첫 요소
- 필요 시 닉네임 오른쪽에 작은 상태 텍스트
- 이미지가 빠진 자리에 불필요한 여백을 두지 않음

### 진행률

- 높이 6~8px
- 회색 트랙 + cobalt 채움
- 우측에 `3 / 5회` 또는 퍼센트 표시

### 체크인 사진 썸네일

두 가지 레이아웃 중 현재 화면 밀도에 맞는 것을 선택한다.

**Compact**
- 64~80px 정사각형
- 우측 배치
- radius 10~12px
- `object-cover`

**Feed image**
- 콘텐츠 전체 너비
- 4:3 또는 16:9 aspect ratio
- radius 12px
- `object-cover`

한 화면 안에서는 한 가지 패턴으로 통일한다. 사진 클릭 시 확대 보기에서는 원본 비율과 `object-contain`을 사용한다.

### 활동 리스트

- 닉네임 / 시간 / 인증 방식 / 메모 / 실제 사진으로 구성
- 프로필 사진 없음
- 사진 URL이 없으면 텍스트 높이에 맞는 평평한 행
- 사진 URL이 있으면 썸네일 추가

### 하단 탭

- 오늘 / 캘린더 / 그룹 / 설정
- 흰 surface + 위쪽 border
- 활성 탭 cobalt, 비활성 gray
- 떠 있는 pill 형태 금지

## 화면별 구현

### 로그인 `/login`

- 앱 로고 이미지와 앱명 사용 가능
- 이메일 필드, CTA 중심
- 인물 스톡 사진은 사용하지 않음

### 온보딩 `/onboarding`

- Step 1: 닉네임
- Step 2: 헬스장 GPS 등록
- Step 3: 주간 목표
- 한 화면 한 질문
- 사용자 얼굴이나 아바타 선택 과정은 추가하지 않음

### 오늘 `/today`

구조:

1. `안녕하세요, {닉네임}님`
2. 이번 주 `3 / 5회`와 7일 출석 레일
3. 큰 `오늘 헬스 감` CTA
4. 오늘 또는 최근 기록 리스트

기록 표시:

- 사진 인증 + 사진 URL 있음: 실제 썸네일 표시
- GPS 인증: 이미지 없이 위치 아이콘과 텍스트만 표시
- 사람 표시는 닉네임만 사용
- 썸네일 클릭 시 확대

### 캘린더 `/calendar`

- 월요일 시작
- 체크인 날짜 도트/색 표시
- 날짜 선택 시 상세 기록 표시
- 상세 기록에 사진 인증 사진이 있으면 썸네일 표시
- GPS 기록에는 이미지 placeholder 없음
- 사용자 이름은 닉네임 텍스트만

### 그룹 `/groups`

- 그룹명과 스위처
- 초대 링크 복사
- 멤버별 진행률
- 최근 활동 피드

멤버 진행률:

```text
운동러                          3 / 5회
━━━━━━━━━━━━━━━━━━
```

- 프로필 사진/이니셜 아바타 없음
- 닉네임부터 시작

최근 활동:

- 사진 인증이면 실제 체크인 사진 표시
- GPS 인증이면 이미지 없이 텍스트만
- 사진을 누르면 확대

### 그룹 없음 `/groups`

- 비인물 일러스트 또는 간단한 아이콘 사용 가능
- 큰 CTA 하나
- 사람 얼굴 캐릭터는 필수 아님

### 새 그룹 `/groups/new`

- 그룹명 입력 + 만들기 CTA

### 초대 `/join/[code]`

- 그룹명과 참여 상태 중심
- 참여 멤버의 얼굴 이미지는 표시하지 않음

### 설정 `/settings`

- 닉네임
- 주간 목표
- 헬스장
- 그룹 관련 설정
- 로그아웃
- 프로필 사진 등록/변경 기능을 새로 추가하지 않음

### 체크인 플로우

- idle → gps → 성공 또는 photo-required → saving → done/error
- photo-required에서 기존 카메라 촬영 기능 유지
- 촬영 후 preview가 기존 UX에 있다면 표시
- 저장 후 실제 사진이 기록 목록에 표시되는지 확인

## 이미지 로딩 문제 해결 지침

`01_IMAGE_POLICY_CORRECTION.md`의 기술 점검을 따른다.

특히 다음을 금지한다.

- 이미지가 안 보인다는 이유로 렌더링 컴포넌트를 제거
- 사진 URL 대신 가짜 placeholder만 표시
- 스토리지 전체 공개 전환
- 모든 외부 호스트를 wildcard로 허용
- 기존 사진 필드를 무시하고 임의 필드 추가

현재 데이터 모델의 실제 필드와 API 흐름을 추적한다.

## 작업 순서

1. 코드베이스/라우트/컴포넌트 조사
2. 이미지 업로드 → 저장 → API → 렌더링 흐름 조사
3. 이미지 미표시 원인과 수정 대상 파일 보고
4. 디자인 토큰과 공통 컴포넌트 정리
5. 오늘 탭과 체크인 사진 복구
6. 그룹 피드 사진 복구
7. 캘린더 상세 사진 복구
8. 프로필 이미지/아바타 제거 및 닉네임-only 적용
9. 나머지 화면 코발트 UI 적용
10. lint/typecheck/build 및 모바일 검증
