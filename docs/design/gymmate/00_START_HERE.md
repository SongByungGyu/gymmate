# GymMate UI 수정 — Claude Code 시작 문구

아래 문구를 Claude Code에 그대로 전달한다.

```text
이전 UI 지시에서 "사진을 사용하지 않는다"는 조건이 잘못 전달되었다.
그 조건을 폐기하고 아래 문서 기준으로 현재 구현을 수정해줘.

먼저 다음 파일을 모두 읽어줘.

- docs/design/gymmate/01_IMAGE_POLICY_CORRECTION.md
- docs/design/gymmate/02_UI_IMPLEMENTATION_GUIDE.md
- docs/design/gymmate/03_gymmate-cobalt-ui-reference.png
- docs/design/gymmate/04_original-design-brief.md

가장 중요한 정정사항:

1. 체크인 사진과 앱의 일반 이미지는 정상적으로 사용하고 화면에 표시한다.
2. 사용하지 않는 것은 "사용자/멤버의 프로필 사진"뿐이다.
3. 사용자 식별은 아바타나 이니셜 원 없이 닉네임 텍스트만 사용한다.
4. 사진 인증 기록에는 실제 체크인 사진 썸네일을 표시하고, 누르면 확대해서 볼 수 있게 한다.
5. GPS 인증 기록처럼 사진이 없는 항목에는 빈 이미지 박스나 가짜 placeholder를 만들지 않는다.
6. 기존 카메라 촬영, 업로드, 저장, 조회 기능과 데이터 계약을 유지한다.
7. 참조 이미지 속 사람 얼굴 아바타는 구현하지 않지만, 운동 인증 사진 썸네일과 앱 로고·아이콘·일러스트·상태 이미지는 사용할 수 있다.

바로 UI만 덮어쓰지 말고 다음 순서로 작업해줘.

A. 현재 이미지 데이터 흐름 조사
- 체크인 촬영 컴포넌트
- 업로드 요청과 저장 필드
- API 응답의 사진 URL 필드
- 오늘 기록, 캘린더 상세, 그룹 활동에서 사진을 그리는 컴포넌트
- Next.js 이미지 허용 도메인 또는 스토리지 URL 설정

B. 이미지가 보이지 않는 원인을 먼저 찾고 보고
- 렌더링 코드가 제거되었는지
- URL 필드명이 달라졌는지
- signed URL이 만료되는지
- next/image remotePatterns 설정 문제인지
- CSS의 overflow, width, height, aspect-ratio 문제인지
- 클라이언트/서버 컴포넌트 경계 문제인지

C. 수정 예정 파일 목록과 구현 계획 제시

D. 수정
- 프로필 사진/아바타 제거
- 닉네임 텍스트만 유지
- 실제 체크인 사진 렌더링 복구
- 썸네일 확대 보기 구현 또는 기존 기능 복구
- 코발트 블루 디자인 유지

E. 검증
- 사진 인증 1건 생성
- 업로드 직후 표시 확인
- 새로고침 후 표시 확인
- 오늘 탭, 캘린더 날짜 상세, 그룹 최근 활동에서 표시 확인
- GPS 인증 기록에는 이미지 영역이 없는지 확인
- 320px, 375px, 428px 너비 확인
- iPhone Safari/PWA에서 카메라 입력과 이미지 표시 확인
- lint, typecheck, production build 실행

현재 기능이나 API 스키마를 임의로 새로 만들지 말고, 실제 코드에 존재하는 필드와 흐름을 추적해서 고쳐줘.
```
